# Evidencias AgroManager

Carpeta de evidencias del TFG sobre comparación de herramientas de IA aplicadas al desarrollo de software mediante el caso práctico AgroManager.

## Estructura

- `codex/`
- `deepseek/`
- `claude/`

Dentro de cada herramienta hay evidencias para `fase08`,`fase09`, `fase10` y `fase11`:

- `01_respuesta_ia.md`: respuesta o resumen final de la herramienta.
- `02_tests_backend.txt`: salida de tests backend.
- `03_build_frontend.txt`: salida de build frontend.
- `04_validacion_visual.md`: checklist de validación visual/manual.
- `05_capturas/`: carpeta para capturas de pantalla.
- `06_notas_incidencias.md`: incidencias, ajustes y observaciones.
